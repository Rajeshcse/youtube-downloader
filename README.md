# YouTube Downloader

A simple GUI application to download YouTube videos and audio using Python and Tkinter.

## Features

- Download YouTube videos in MP4 format
- Download YouTube audio in MP3 format
- Download both video and audio simultaneously
- Progress bar to track download status
- Modern and user-friendly interface

## Requirements

- Python 3.x
- pytube
- tkinter (usually comes with Python)

## Installation

1. Clone this repository:

```bash
git clone https://github.com/yourusername/youtube-downloader.git
cd youtube-downloader
```

2. Install the required packages:

```bash
pip install -r requirements.txt
```

## Usage

Run the application:

```bash
python main.py
```

1. Enter a YouTube URL in the input field
2. Select the download type (Video, Audio, or Both)
3. Click the Download button
4. Wait for the download to complete
5. The downloaded files will be saved in the respective folders (videos/ or audio/)
